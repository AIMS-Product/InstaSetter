# Persona 12 — ALEX (Developer)

**Archetype:** 29yo full-stack engineer, TypeScript + React shop. Keeps DevTools open. Inspects network, reads console, judges render perf. Thinks in z-index stacks and hydration graphs.
**Lens:** Is this well-built? Do the forms validate? Are there console errors? Does state update atomically? Are internal errors contained or leaking? Is the URL sensible? Is there layout shift? Are optimistic updates honest about failure?
**Frustration triggers:** console noise, pointer-events intercepts, silent failures, leaky server errors, framework artifacts visible in prod, env-var boot errors surfaced as user UI, busted tabs, 404s on routes that existed five seconds ago.

---

## Overall gut score: 1.5 / 5

> "I opened DevTools and immediately lost respect. There's a `ZodError: [ANTHROPIC_API_KEY]` being logged to the browser console on the home page — a **server-side env validation failure is leaking into the client bundle**. The Flow Builder has **fourteen buttons that are physically unclickable** because a sibling div is eating every pointer event. The Conversations page returns 200 and then renders an error state because the service call throws on an invalid env. This isn't polish — it's broken."

## Category summary

### Navigation & Flow

- Tabs aren't in the URL (finding #6). Can't deep-link, bookmark, or share a view.
- `/dashboard` has no nav shell (finding #10). Users can't traverse the app.
- Home → Dashboard → Flow Builder works; from Flow Builder there's no breadcrumb back.

### Copy & Labels

- Hero says what the product is _called_, not what it _does_ (finding #9).
- Error messages are generic to the point of useless (finding #3).
- Icon-only controls have no tooltips (findings #7, #17).

### Forms & Input

- Block-config textareas have no `name`, no `label` association, no validation (finding #8).
- Simulator Send has no inflight guard (finding #20).
- "Publish v13" is unguarded (finding #13).

### Visual & Layout

- Blocks drawer overlays the tab strip (finding #5) — actual cause of the pointer-events bug.
- Mobile viewport unsupported but not gated (finding #15).
- Pages are visually indistinguishable from each other (finding #18).

### Feedback & State

- **Pointer-events intercept blocks 14 controls (finding #4).** This is the single worst bug in the build.
- Conversations page crashes silently behind a 200 + generic error screen (finding #2).
- No dirty/saved state indicator on the builder (finding #14).
- "Try again" button doesn't actually recover (finding #2).

### Trust & Safety

- `ZodError` leaks env var names to the browser console (finding #1).
- Publish is a one-click irreversible prod-write (finding #13).
- Destructive delete buttons unguarded (finding #19).

### Accessibility

- Icon-only unicode-glyph buttons with no `aria-label` throughout (finding #17).
- No visible focus styles verified in screenshots (would need keyboard trace to confirm, but suspicious).
- Mobile layout broken (finding #15).
