# UX Persona Review

App: InstaSetter
URL: http://localhost:3000
Date: 2026-04-20
Pages tested: 5 (Home, Dashboard, Conversations, Flow Builder, 404). Conversation detail page was skipped — no conversations seeded in dev DB.
Interactions tested: 34+ screenshots across 3 viewports (desktop 1280×800, mobile 375×667, tablet 768×1024)
Screenshots captured: 34
Personas: 15

---

## Executive Summary

- Total unique issues: 58
- P0 Critical: 10
- P1 High: 17
- P2 Medium: 20
- P3 Low: 11
- Blockers flagged by at least one persona: 12
- Average gut feel across all personas, all pages: 1.8/5

The product is not ship-ready. Every persona — from a 78-year-old grandparent to a seasoned developer — scored it below 2/5 overall, and the root causes cluster tightly. A transparent DOM overlay in the Flow Builder blocks 14 primary controls across every tab (flagged by 14/15 personas). The Conversations page — the home page's primary CTA — crashes on first load because a missing `ANTHROPIC_API_KEY` is being surfaced as a generic `error.tsx` fallback (flagged by all 15). And there is no trust chrome anywhere: no footer, no support link, no pricing, no account context, no kill switch for a bot that is "Live on v12 · 42 convos today." As Karen put it: "Indistinguishable from an abandoned product." The one bright spot every persona agreed on is the 404 page (mean 3.3/5), which ironically has the clearest copy and cleanest layout in the app.

## Category Breakdown

### Navigation & Flow

The app has no persistent chrome (P0.6, 13/15). Every page is an island — no logo-as-home, no sidebar, no breadcrumbs, no account context. Error pages (P1.9, 8/15) don't even preserve a way back. Flow Builder's state-based tabs lose URL deep-linking (P2.1). The home page dumps strangers straight into authenticated-looking admin surfaces (P1.14, 5/15). Mobile has no bottom tab bar (P1.8, 5/15) — punishing for the IG-marketer audience. **Top fixes:** add a persistent app shell with nav + breadcrumbs + account indicator + env badge; add "back to home" links on every error page; gate `/dashboard/*` behind auth.

### Copy & Labels

Three overlapping problems. (1) Jargon: "Flow/Block/Bot/Qualifier/Escalation/Persona/Publish v13/IG Organic DM/prospect/convos" overwhelms non-specialist readers (P0.4, 14/15). (2) Error copy is "Something went wrong. An unexpected error occurred." with no cause, no code, no support path (P0.8, 14/15). (3) Internal dev copy leaks: "Flow Builder preview", "prototype flow", "ships in Week 7" (P1.16, 5/15). The home tagline (P0.9, 11/15) communicates nothing to a stranger. **Top fixes:** plain-English block names, glossary page, proper error copy with incident IDs, remove all "preview/prototype/Week N" language, lead the home page with benefits.

### Forms & Input

Every editable surface is unlabelled (P0.10, 10/15) — no `name`, no `<label>`, no `placeholder`, no required marker, no validation, no dirty/save state. The simulator Send (P1.7, 7/15) hits real Claude with no loading guard and no "this is sandboxed" label. No keyboard shortcuts (P1.15, 4/15), no command palette, no keyboard alternative to drag-drop canvas editing. **Top fixes:** wire `aria-labelledby` on every textarea; ship autosave + dirty pill; add a sandbox banner over the simulator; build Cmd+K and `?` cheatsheet.

### Visual & Layout

Three design languages coexist (P1.6, 5/15): marketing Tailwind, error-fallback generic, and hand-rolled inline-styled Flow Builder. No shared tokens. Mobile is unsupported but not gated (P1.8). Flow Builder panels collide at 1280×800 (P1.5, 7/15). No minimap, no dockable panels. The home hero is 70% whitespace; the Flow Builder is 300% overstuffed — nothing in between. **Top fixes:** `@/lib/design-tokens` with one scale for everything; mobile breakpoint for Flow Builder; dockable/resizable/closable panels; minimap; loading skeletons.

### Feedback & State

The Conversations crash (P0.1, 15/15) is the most-flagged issue in the entire review. The pointer-events overlay (P0.2, 14/15) is the second. Neither was caught before this review. No bot status (P1.4, 7/15) — the single most important signal for every operational persona (Tom, Priya, Victoria). No autosave indicator (P1.3, 7/15). No toasts (P2.14). Publish is silent (P0.5 / P1.4). **Top fixes:** fix the env config so Conversations doesn't crash; fix the overlay z-index; add a persistent "Bot: LIVE" pill; add toasts on every mutation; autosave everything.

### Trust & Safety

No footer (P0.7, 10/15). No pricing, no company info, no Meta partner status, no ToS, no Privacy, no DPA, no security badges (P1.11, 6/15). Publish has no safety net on a live bot (P0.5, 10/15). No kill switch (Blocker #7, 2/15 but severity is life-or-death for operators). Internal `ZodError` leaks env var names to console (P0.7). Unauthenticated access to `/dashboard/*` (P1.14, 5/15). **Top fixes:** global footer with all legal links; Publish modal with diff + confirm + rollback; persistent pause-bot toggle; gate dashboard behind auth; redact server errors from client console.

### Accessibility

Zero `:focus-visible` styles anywhere (P1.1, 9/15). Icon-only Unicode glyphs with no `aria-label` (P0.3, 15/15). No landmarks, no skip-link (David's #1 and #2 findings). Tab state not exposed to ARIA (P1.10, 9/15). Mobile broken (P1.8). Color-only encoding on connector lines and chips (P1.10, P2.7). Canvas editing is mouse-only — WCAG 2.1.1 failure (P1.15). No contrast check on grey-on-cream body copy (P2.11, 4/15). **Top fixes:** add global `:focus-visible`; replace glyphs with Lucide + `aria-label`; convert tabs to WAI-ARIA tab pattern; ship canvas keyboard navigation before v1.
