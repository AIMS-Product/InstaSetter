# Persona Review: Marcus — Impatient Power User

**Who I am.** 34, PM, 40+ tools open at any time. Keyboard-first. I evaluate an app in the first three seconds and abandon anything that wastes them. I expect a command palette (Cmd+K), keyboard shortcuts, inline editing, smart defaults, and zero confirm dialogs on reversible actions. I read tooltips only if you earn it. Don't make me hunt.

---

## Summary

InstaSetter looks clean. That's the only thing going for it from a power-user lens. The landing page is four words and two buttons — I'm staring at an empty beige rectangle wondering if the page finished loading. No nav. No command palette. No recent items. No keyboard hints anywhere. The Conversations route errored on first click and threw a generic "Something went wrong." That's an instant trust hit. Flow Builder is dense and ambitious but the toolbar is crammed with single-glyph icons (⊞ ⤢ ∥ ⟳ ◐ ◉ ⎔) with no tooltips, no labels until you hover, and — worst — a real pointer-events bug where a transparent overlay blocks clicks on the primary tabs (Flow / Runs / Variables / Versions / Bot) and several × close buttons. Playwright couldn't click them; a real user would click, get nothing, click again, swear, refresh. That's a blocker.

Publish is a one-click primary button with no confirmation and no "are you sure" — which I normally love — except this ships a prompt that controls a live bot on real prospects. One fat-finger away from a bad deploy. No undo visible. No diff view before publish. No keyboard shortcut (Cmd+S to save, Cmd+Shift+P to publish would be obvious). No command palette anywhere.

Overall: cheap to look at, expensive to actually use.

## Blockers (fix these before shipping)

1. **Conversations route errors on load with a generic "Something went wrong."** (#17, #18, #21) — the most-used route is dead and the real cause (ANTHROPIC_API_KEY Zod failure) is buried in console.
2. **Pointer-events bug in Flow Builder.** (#24) — a transparent overlay is blocking clicks on Flow/Runs/Variables/Versions/Bot tabs and multiple × buttons. Confirmed across every tab in the exploration log. This is a DOM bug, not a test issue.
3. **Dashboard is a one-link page.** (#10, #14) — no metrics, no list of flows, no bot status. A dashboard without data is not a dashboard.
4. **Publish is a single click with no diff, confirm, or rollback.** (#32, #33) — ships a prompt to a LIVE bot against real prospects. This is the one place I want a real safety net, and there isn't one.

## What would make me come back

- **Cmd+K everywhere.** Palette with: "Open conversations", "Open flow", "Publish", "View live prompt", "Switch version", "Jump to block: qualifier".
- **A real dashboard**: live bot status pill, today's convos, booking rate, failure rate, last publish, last 5 flows, shortcuts grid.
- **Keyboard shortcut overlay** on `?` in Flow Builder with the full map.
- **Publish modal** with a diff (current live vs. draft), "deploy to canary / 10% / 100%" stepper, and a prominent rollback button on the post-publish confirmation.
- **Autosave stamp** on every editable field: "Saved · 12:04:17".
- **Tabs with text labels** (or labels + glyph), not glyph-only.
- **Simulator with scenarios**: save a test prospect conversation, re-run on every prompt change, keep a pass/fail grid. That's the killer feature for prompt iteration — ship that and I'll evangelize the product.
- **Fix the invisible overlay.** Before any of the above.

I don't need pretty. I need fast, keyboardable, and safe. Right now it's slow, mouse-only, and one click from shipping bad prompts to live users. Hard pass until the blockers clear.
